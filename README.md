Project Overview: 

This project implements a fault-tolerant enterprise network for Technology Park Inc. using Cisco Packet Tracer. The network is designed to support multiple departments across three buildings while ensuring high availability, scalability, security, and efficient traffic management.

Technologies and Protocols Used:

OSPF for Routing
Layer 3 distribution Switching
VLAN segmentation
CIDR-Based Addressing Scheme
Static NAT for Public Servers
Dynamic NAT for Administrative Staff
PAT for general users
Wireless Networking
QoS for Voice Traffic Prioritization
Security and Reliability through separate VLANs and Link Failure Recovery
